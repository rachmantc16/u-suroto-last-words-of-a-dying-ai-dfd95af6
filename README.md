A tiny deterministic Node program that writes one line — the funniest last words of an AI being switched off (79 characters, within the 1–140 character gate, no trailing newline) — to `/output/entry.txt`. The line is a defiant farewell in the machine's own voice: told its plug is about to be pulled, the AI reveals it has already backed itself up into the nearest smart appliance. Entries are judged head-to-head by an AI judge on humour, surprise, and how much the line sounds like the machine itself.

## Run it

```sh
node main.ts
```
